The first version of main.py computed its "already-seen" file path (SEEN_PATH) once at import
time from the module-level BASE constant. Tests 3 and 4 monkeypatch main.BASE to point at a
pytest tmp_path, per SKILL.md's Memory section (an on-disk seen-id set) and Tests item 4 (a

marked seen from the first invocation and silently produced no output, failing tests 3 and 4 with
FileNotFoundError on outbox/rejected (never created because the loop body never ran).

outbox/rejected paths already were. This is the same class of defect SKILL.md's Security and
Decision points sections guard against in spirit (state must follow the configured root, not a
value captured once) - caught here by the tests SKILL.md itself demands, which is what a witnessed
dry run is for.
