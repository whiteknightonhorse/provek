RED-007 - a law whose gate and test never leave this host, 2026-08-20

T-DECISION-1 asked Path.exists() and nothing else. Five LAW-NOTES-* entries were written into
a TRACKED enforced_by.yaml while their gate (web/notes/emit.mjs) and their test modules were
still UNTRACKED. Every gate went green: the files were on this disk, so they existed. In any
clone the same five laws name files that are not there, and the ratchet that exists to catch
a law without an armed gate would itself have shipped five of them.

This is not an injected defect. It is the state the tree was actually in when T-E1 read it,
and it is L-3 turned on the law registry: what the consumer receives is the clone.

$ python3 scripts/ratchet_decisions.py   # before git add
