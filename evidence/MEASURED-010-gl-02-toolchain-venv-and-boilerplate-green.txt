3. TWO NAMED TOOLCHAIN DEFECTS (not silently worked around - see GL-harness-notes.md §7 for detail)
--------------------------------------------------------------------------------------------------

3a. PyPI metadata for `genlayer-test==0.29.2` declares `genlayer-py<0.17.0,>=0.13.0`
(`pypi.org/pypi/genlayer-test/0.29.2/json` -> `info.requires_dist`), which conflicts with the
pinned `genlayer-py==0.18.0` and made `uv pip install` refuse to resolve all three together.
Checked against the actual source at the boilerplate's own pin
(`raw.githubusercontent.com/.../genlayer-testing-suite/v0.29/pyproject.toml`): it declares
`genlayer-py>=0.18.0,<0.19.0` - the PyPI-published metadata is stale, the real requirement matches
0.18.0. Fixed by installing `genlayer-test` with `--no-deps` and installing its actual runtime
deps directly (§1).

3b. `gltest`'s direct-mode SDK downloader (`gltest/direct/sdk_loader.py`) resolves "latest genvm"
via the redirect of `github.com/genlayerlabs/genvm/releases/latest`, which today lands on
`v0.3.0-rc7`, then requests asset `genvm-universal.tar.xz` under that tag. That asset name has not
existed since `v0.2.16` (checked via `api.github.com/repos/genlayerlabs/genvm/releases`, every
release from `v0.3.0-rc0` on ships per-platform assets instead) - so this request 404s for ANY
contract on a fresh host, not something specific to this repository. Verified `v0.2.16`'s
`genvm-universal.tar.xz` still contains the exact runner hash
(`1jb45aa8ynh2a9c9xn3b7qqh8sm5q93hwfp7jqmwsfhh8jpz09h6`) that `contracts/football_bets.py`'s pinned
header requires (inspected the tarball's `runners/py-genlayer/1j/b45aa8yn....tar` member directly),
so it is the matching runtime, not a stale substitute. Fixed by pre-populating
`~/.cache/gltest-direct/genvm-universal-v0.2.16.tar.xz` so the loader's own existing
cache-first code path (`list_cached_versions()`) finds it before ever calling GitHub - no package
source was edited. This cache file must exist for GL-03's own `pytest tests/direct` run to go
green; it is not part of this repository and not deleted by this task's scratch cleanup.
