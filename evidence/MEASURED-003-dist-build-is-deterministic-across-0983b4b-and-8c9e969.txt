WHAT THIS DOES NOT COVER, NAMED RATHER THAN LEFT IMPLICIT (Fable round 3 refutation,
2026-08-25T03:1xZ, caught the two absences below in a draft of this file that did not name them):

1. `deploy-label.txt` itself. `~/orchestra/deploy.sh` calls `deploy_stamp.sh stamp` AFTER
   `npm run build` and BEFORE `wrangler pages deploy` - the label is written directly into `dist`
   as a build step of its own, never produced by `npm run build`. Neither listing above contains a
   `deploy-label.txt` line at all (`find ... -iname 'deploy-label*'` on both `dist/` returned
   nothing) - the digest is structurally blind to the one file the live lag is actually about. The
   live site necessarily still reads `8c9e969` in that file until a real deploy runs; this
   measurement does not close that gap and was never able to.
2. The Cloudflare Pages Functions bundle (`web/functions/`, backing `/api/apply`). `wrangler pages
   deploy dist` reads Functions from the working directory, not from inside `dist/`, so `find dist`
   never sees it and this digest says nothing about it. `wrangler@4` is pinned by neither exact
   version nor lockfile-frozen output (deliberately, per D-26), so a fresh deploy could bundle
   Functions with a newer wrangler minor than the one that produced the live deployment - a
   difference this measurement cannot see and does not claim to rule out.

WHAT IS ESTABLISHED, PRECISELY. `web/dist` built from `HEAD` (`0983b4b`) is byte-identical, file by
file, to `web/dist` built from the labelled commit (`8c9e969`) - for the STATIC ASSET TREE ONLY, not
for the deploy stamp and not for the Functions bundle. Combined with the source-level diff already
showing no changes under `web/` between the two commits, this is a second, independent confirmation
(build-path determinism) of a fact the diff already implied, not a proof that a fresh deploy of
`HEAD` would be indistinguishable from what is currently live.

Both `dist/` directories and both raw listings were removed from `/tmp` after this file was written;
this artefact is what remains, per the disk budget (10 GB, this host, ten projects).
