RED-027 - a pinned pip line is one edit away from unpinned, and nothing here could see it
====================================================================================================

WHY THIS FILE EXISTS. D-30 replaced three `pip install` lines in `.github/workflows/gates.yml` with
hash-checked requirement sets. The first draft of that decision argued that NO gate was possible -
that "the set was moved by somebody who read what changed" is a fact about an edit rather than
about the tree, and so belonged to L-8's honestly-gateless class. Fable refused the change over it.
The argument was true of the JUDGEMENT and false of the SHAPE: whether `--require-hashes` is still
on the line is a fact about the tree, readable offline, and able to go red. Under cover of the
unmeasurable half, the measurable half was being waved through.

The aggravating detail, and the reason the reverted line is not merely theoretical: no other gate
in this repository can see this edit. `tests/test_door_matches_ci.py` classifies any step whose
command begins `pip install` as runner preparation, so a line reverted to bare packages is waved
through as setup by the gate specifically built to catch steps that slipped past the table. The
OpenSSF scan would raise a fresh `PinnedDependenciesID` days later, in a tab nobody is reading at
the moment of the push.

WHAT WAS DONE. Line 128 of `gates.yml` was edited back to the exact text that stood there before
D-30 - `- run: pip install --quiet pytest pytest-cov` - and the gate and its suite were run against
that tree. The file was restored from a byte copy afterwards and its sha256 verified identical, per
the rollback rule in CLAUDE.md; no `git` restore was used, so nothing untracked was at risk.

WHAT THIS PROVES AND WHAT IT DOES NOT. It proves the law can FAIL, on the one edit it exists to
catch, which is invariant 5. It does not prove the digests in the committed sets are the ones PyPI
serves - that is not checked from this tree at all, and does not need to be: `pip` recomputes every
hash at install time and refuses the artefact on a mismatch. The division is deliberate and is
written out in the docstring of `scripts/verify_pip_pins.py` - pip enforces truth on every run, and
what is left for a gate is the shape pip never gets to see, namely whether it was asked to.
